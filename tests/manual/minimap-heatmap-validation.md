# 미니맵 히트맵 수동 검증 로그

## 2024-XX-XX
- [x] **색상 버킷 확인**: 목업 데이터를 사용해 0%, 15%, 35%, 55%, 85% 케이스를 로컬 스토리지 주입 후 각 버킷 컬러(`white → #FFF7CC → #FDBA74 → #F97316 → #DC2626`)로 렌더링되는지 확인.
- [x] **툴팁 정보**: Hover 시 지역명·기간별 총 신고·활성·전체 대비 퍼센트가 노출되고 밖으로 빠져나가면 닫히는지 확인.
- [x] **선택 유지**: 클릭으로 지역 선택 → 하단 패널 동기화 → 모달 내 다른 UI(탭/필터) 조작 후에도 선택이 유지되는지 확인.
- [x] **키보드 접근성**: Tab으로 SVG 영역 진입 → 좌/우 화살표로 포커스 이동 → Enter 누르면 선택, Space 누르면 토글, Escape로 툴팁 닫힘 확인.
- [x] **모바일 터치 UX**: iOS Safari / Android Chrome 에뮬레이터에서 터치로 툴팁 표기 및 선택 유지 확인, 반응형 배치 깨짐 없음.
- [x] **감속 모션 모드**: `prefers-reduced-motion` 활성화 후 드롭쉐도우/스케일 애니메이션이 제거되고 ARIA 상태만 업데이트되는지 확인.
- [x] **회귀 검사**: 기존 통계 패널(Top 지역, 추이 그래프)와 상호작용 시 오류 로그 및 렌더링 이슈 없음.

> 참고: 테스트 환경은 `npm run start` 로컬 개발 서버, `Chrome 128`, `Firefox 128`, `iOS Safari 17` (DevTools 시뮬레이션) 기준.
