# MissingAlert 공공데이터 3개월 실증 제안 초안

## 목적

지자체·경찰과 함께 공식 공개 실종정보의 시민 접근성과 안전한 확산을 검증한다. 공식 신고·수사 업무를 대체하지 않는다.

## 기간과 범위

- 기간: 합의한 시작일로부터 3개월
- 대상: 합의 지역의 공식 active 공개 사건과 경찰청 공개 통계
- 채널: MissingAlert 지도·검색·통계·공유·공식 제보 경로
- 제외: 수사 판단, 민감 제보 원문 공유, 기관 확인 없는 발견 기여 주장

## 공동 확인 지표

- 공개 실종정보 노출·상세조회·공유·공식 원문 이동·제보 CTA 클릭
- 데이터 동기화 성공률과 마지막 확인 시각
- 데이터 품질 이슈 발견·처리 시간
- 종결 정보 공개 제외 시간

모든 행동 지표는 정의된 이벤트 횟수이며 실제 시민 수·제보 제출·발견 성과와 구분한다.

## 운영·보호

- 사건별 공식 출처와 확인 시각 표시
- Analytics 개인식별정보 금지
- 공개 전 월별 원시 집계 대조와 관리자 승인
- 종결·비공개 요청 즉시 처리 경로
- 월 1회 지표·품질 공동 검토

## 종료 산출물

- 3개 월의 승인된 Impact 증거팩
- 원본→정규화→공개 화면 대조 자료
- 데이터 정정 및 종결 처리 사례
- 과대 표현을 제거한 1페이지 활용사례서
