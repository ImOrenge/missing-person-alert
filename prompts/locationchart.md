# 지역별 실종 통계 모달 & 모바일 대시보드 개선 체크리스트

모바일 관리자 환경을 기준으로 실시간/누적 통계 카드, 차트, "시·군·구 통계보기" 모달을 페이즈별로 고도화하는 계획입니다. 각 페이즈는 완료 조건을 체크리스트로 관리합니다.

## 공통 준비
- [x] 모바일/데스크톱 주요 단말 목록 확정 및 QA 범위 정의
- [x] Firestore 집계 스키마(`stats/regionDaily`, `regionMetadata`, `appMetrics/visitorStats`)와 호출 API 명세 정리
- [x] 접근성(A11y)·성능(Lighthouse)·번들 사이즈 측정 기준 수립
- [x] 디자인 시스템 토큰(색상, 간격, 타이포) 업데이트 및 모바일 가이드 별도 문서화

## Phase 1 – 접근성 확보 & 기본 구조 정비
### 목표
- 모바일에서도 핵심 KPI, 누적/실시간 방문, 최근 제보를 한 화면 내에서 파악할 수 있도록 레이아웃을 재구성하고, "시·군·구 통계보기" 모달의 기본 접근성을 확보합니다.

### UX/UI 체크리스트
- [x] 메인 헤더(데스크톱) & FAB(모바일)에 `통계 보기` CTA 배치, `aria-label`과 24시간 유지되는 `New` 배지 적용
- [x] 통계 요약 카드 모바일 싱글 컬럼화, 숫자 단위(천/만) 축약 포맷 적용
- [x] 차트/리스트 로딩 시 Skeleton & Spinner 처리, 오류 토스트 표준화
- [x] 시·군·구 모달을 모바일 풀스크린으로 전환하고 상단에 최신화 시각·출처·지원 연락처 표기
- [x] 모달 하단 고정 액션 바에 닫기, 개인정보 안내, 피드백 채널 링크 제공

### 데이터 & 엔지니어링 체크리스트
- [x] Cloud Scheduler → Cloud Function으로 `stats/regionDaily`(regionId, date, totalCases, activeCases) 1시간 주기 집계
- [x] `regionMetadata` 서브컬렉션 설계(행정코드, 좌표, 상위지역) 및 캐싱 전략(15분 TTL) 적용
- [x] 통계 탭에서 Firestore 누적 방문(`appMetrics/visitorStats`) 구독 시 실패 핸들러 & Graceful fallback 구현
- [x] 단말별 터치 영역 최소 44px 확보, 색 대비 4.5:1 준수, Screen Reader 라벨 점검

## Phase 2 – Drill-down & 상호작용 강화
### 목표
- 지역 Drill-down 흐름을 명확히 하고, 지도/차트 조합 뷰와 데이터 새로고침 UX를 개선합니다.

### UX/UI 체크리스트
- [ ] 시·도 선택 시 시·군·구 뷰로 전환, breadcrumb & `전체 목록` 버튼 제공
- [ ] 필터 상태를 URL 쿼리(`?region=11&sub=11010`)로 동기화, 공유/북마크 지원
- [ ] 모바일 모달에서 지도/차트 탭 전환 및 스와이프 제스처 적용, 탭 인디케이터 시각 피드백
- [ ] 즐겨찾기/내 위치 필터, 필터 토글 시 하단 Toast 피드백
- [ ] 상단 KPI 카드에 최근 30일 대비 증감률, 전국 평균 대비 편차 표기

### 데이터 & 엔지니어링 체크리스트
- [ ] 지도 Choropleth & 막대 차트 컴포넌트를 분리(`MapView`, `RegionChart`), lazy loading 적용
- [ ] hover/포커스 툴팁을 키보드 접근 가능하도록 포커스 트랩/ARIA 속성 반영
- [ ] 모달 하단 툴바에 `데이터 새로고침` 버튼, 마지막 요청 시각, 로딩/에러 상태 분기 구현
- [ ] 통계 기준(신고 건수 vs 인구 대비)을 정보 토글 섹션에 명시하고 향후 필터 로드맵 안내

## Phase 3 – 고급 시각화 & 최적화
### 목표
- 기간 비교, 고급 지표, 접근성/성능 자동화를 강화해 장기 유지보수를 대비합니다.

### UX/UI 체크리스트
- [ ] 7/30/90일 및 전체 기간 비교 멀티 축 차트 구현, 전년 동월 대비 KPI 카드 추가
- [ ] 레이아웃을 2열↔1열 반응형으로 전환하고 인피니트 스크롤 제거, 한 화면 내 핵심 지표 수렴
- [ ] CSV/Table 다운로드 버튼 제공, 모션 감도 낮추기(`prefers-reduced-motion`) 감지 시 애니메이션 비활성화
- [ ] 색각 보정 팔레트 적용, 키보드 단축키(`?`)로 차트/모달 조작 도움말 노출

### 데이터 & 엔지니어링 체크리스트
- [ ] Cloud Function 집계 Job에 재시도/Slack Webhook 알림, BigQuery Export 파이프라인 옵션 검토
- [ ] `StatisticsModal` 컨테이너와 `SummaryPanel`·`Charts`·`MapView` 등 서브 컴포넌트 분리, Storybook 사례 추가
- [ ] Lighthouse CI(모바일) & Playwright 시각 회귀 테스트를 배포 파이프라인에 편입
- [ ] 번들 사이즈 모니터링 및 코드 스플리팅(차트 라이브러리) 적용, 성능 회귀 알림 구성

## 완료 조건
- 각 Phase 체크리스트 100% 체크 → 디자인·QA 승인 → 스테이징 사용자 테스트 → 프로덕션 배포 순으로 진행
- 체크리스트 미충족 항목은 Phase 종료 보고서에 원인/보완 계획을 기록하고 다음 스프린트로 이관
