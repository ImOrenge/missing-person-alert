# 지역별 실종자 통계 모달 – 페이즈별 개선안

## Phase 1 – 접근성 확보와 기본 통계
- **통계 보기 버튼 노출**  
  - 메인 헤더 상단 우측과 모바일 플로팅 액션에 `통계 보기` 버튼을 노출하고, 스크린 리더용 `aria-label="지역별 실종자 통계 모달 열기"`를 부여.  
  - 실시간 데이터가 새로 반영된 경우 `New` 토글 배지를 24시간 표시해 재방문자를 유도.  
  - 클릭 시 풀스크린 모달을 열고 상단 고정 영역에서 데이터 최신화 시각·출처(Firestore 컬렉션 이름)·연락처를 명시.
- **기본 차트 레이아웃**  
  - 상단에는 `최근 실종 신고 현황` 제목과 함께 기간 필터(일·주·월·전체/커스텀 날짜)를 제공하며, 필터 변경 시 로딩 스피너와 스켈레톤 UI를 표시.  
  - 본문에는 전국 시·도별 막대 차트를 배치하고 값이 0인 지역도 회색 막대로 노출해 분포를 직관화, 모바일에서는 스크롤 가능한 카드형 리스트/스택 막대 차트로 자동 전환.  
  - 우측(또는 모바일 하단)에는 현재 필터 조건과 상위 3개 지역을 텍스트 카드로 정리해 차트 없이도 핵심 정보를 전달.  
  - 하단에는 닫기 버튼, 개인정보 보호 안내, 실종 데이터 처리 목적 문구, QA 피드백 메일 링크를 함께 제공.
- **집계 데이터 구조 설계**  
  - `missingPersons` 원본을 기준으로 Cloud Function Scheduler가 1시간 주기로 `stats/regionDaily`(`{regionId, date, totalCases, activeCases}`)을 생성/업데이트하도록 설계.  
  - 프런트는 읽기 전용 REST/Firestore 호출만 수행하고, 15분 캐시 TTL을 적용해 반복 로드를 방지.  
  - 향후 확대를 대비해 `regionMetadata`(행정코드, 좌표, 상위지역) 서브컬렉션을 생성해 지도 시각화에 재사용.

## Phase 2 – Drill-down 및 상호작용 강화
- **지역 Drill-down**  
  - 시·도 드롭다운/지도 클릭으로 지역을 선택하면 중앙 카드가 해당 시·군·구 히트맵/막대・도넛 차트로 전환되고, 선택 히스토리를 breadcrumb로 노출.  
  - 드릴다운 시 필터 스테이트를 URL 쿼리(`?region=11&sub=11010`)로 동기화해 공유 가능하게 하고, escape/`전체 목록 보기` 클릭 시 최상위로 복귀.  
  - 상세 차트 상단에는 최근 30일 대비 증감률, 전국 평균 대비 편차를 텍스트로 강조.
- **지도/차트 조합**  
  - 데스크톱: 좌측에 Choropleth 지도, 우측에 지역별 막대 차트와 표를 스플릿 레이아웃으로 구성하고, 범례/색상 스케일 설명을 지도 하단에 고정.  
  - 모바일: 지도와 차트를 탭으로 분리하고, 스와이프 제스처/탭 인디케이터를 제공해 하향식 탐색을 돕는다.  
  - 모든 hover/포커스 이벤트에서 툴팁을 키보드 접근 가능하게 처리하며, 지도 줌 레벨에 따라 라벨 밀집도를 조정.
- **데이터 새로고침/단위 안내**  
  - 모달 하단 툴바에 `데이터 새로고침` 버튼과 마지막 요청 시각을 표기하고, 새로고침 중 로딩 상태 및 에러 토스트를 노출.  
  - 통계가 `신고 건수` 기준임을 명시하고, 인구 대비 비율/연령 필터는 향후 Phase 3에서 제공 예정임을 안내.  
  - 데이터 업데이트 주기, 소스, 문의 채널을 `정보` 토글 섹션에 정리해 신뢰도 확보.

## Phase 3 – 고급 시각화 및 접근성 최적화
- **누적/기간별 비교 시각화**  
  - 최근 7일·30일·90일·전체 기간을 동시 비교하는 멀티 축 라인/에어리어 차트를 제공하고, 축 범위 자동/수동 토글을 지원.  
  - 기간 필터를 변경하면 차트/표/하이라이트 카드가 동시 업데이트되며, 증감률과 전년 동월 대비 지표를 계산해 상단 KPI 카드로 노출.  
  - 화면 가용 폭에 따라 2열(데스크톱)↔1열(태블릿/모바일) 레이아웃을 자동 전환하고, 인피니티 스크롤 없이 핵심 지표를 1 화면 내에 수렴.
- **접근성 및 반응형 디테일**  
  - 색각보정 팔레트(Defect Friendly)와 최소 명도 대비 4.5:1을 준수하고, 키보드 포커스 링/단축키(`?` 모달)로 모든 드릴다운 조작 가능하게 확보.  
  - 차트 애니메이션은 200ms 이하로 제한하고, 모션 감도 낮추기 환경설정(`prefers-reduced-motion`)을 감지해 즉시 정적 렌더링 전환.  
  - 모든 수치 데이터를 테이블/CSV 다운로드 버튼으로 제공해 보조공학 사용자도 데이터 접근 가능하도록 지원.
- **성능 및 유지관리**  
  - Cloud Function 집계 Job에 재시도/Slack Webhook 알림을 붙이고, BigQuery Export 옵션을 열어 장기 추세 분석에 대비.  
  - 통계 모달을 `StatisticsModal`(컨테이너)와 `Charts`/`MapView`/`SummaryPanel` 등 서브 컴포넌트로 세분화하고, Storybook에 UI 스냅샷을 추가.  
  - Lighthouse CI나 Playwright 시각 회귀 테스트를 파이프라인에 추가해 배포 전 접근성/시각 일관성을 검증.
