# 지역별 실종자 통계 모달 개발 플랜

## 1. 목표 및 범위
- `prompts/locationchart.md`에서 정의한 Phase 1~3 개선안을 제품 기능으로 단계별 구현
- 실종자 통계 데이터를 Firestore 기반으로 안정적으로 집계·시각화하고, 접근성/반응형 UX를 확보
- Cloud Functions, 프런트엔드 모달 컴포넌트, 테스트/모니터링 체계를 포함한 엔드투엔드 구현

## 2. 단계별 구현 전략

### Phase 1. 접근성 확보와 기본 통계
- **UI 진입점 및 접근성**
  - 헤더/플로팅 액션 버튼에 `통계 보기` CTA 추가, `aria-label`·키보드 포커스 순서 설정
  - 데이터 최신화 시각/출처/문의처를 모달 상단 고정 헤더에 배치하고 `New` 배지 로직 구현
- **기본 레이아웃 & 차트**
  - 기간 필터 컴포넌트(일·주·월·전체/커스텀) 개발, 로딩 스켈레톤/스피너 적용
  - 전국 시·도 막대 차트 + 상위 3개 지역 하이라이트 카드 구현, 모바일 전용 카드/스택형 전환
- **데이터 파이프라인**
  - Cloud Scheduler + Cloud Function으로 `stats/regionDaily` 집계 잡 작성(시간 당 실행)
  - `regionMetadata` 서브컬렉션 설계, Firestore 규칙 및 캐싱 전략(15분 TTL) 정의

### Phase 2. Drill-down 및 상호작용 강화
- **지역 Drill-down UX**
  - 시·도 드롭다운 및 지도 클릭 이벤트 처리, breadcrumb/“전체 보기” 복귀 로직
  - URL 쿼리 동기화(`?region=11&sub=11010`)로 공유 가능하도록 라우터 상태 관리
  - 상세 차트 KPI 텍스트: 30일 증감률, 전국 평균 대비 편차 계산/표시
- **지도+차트 통합 레이아웃**
  - 데스크톱 스플릿 레이아웃(Choropleth 지도 + 막대 차트/표), 모바일 탭/스와이프 UI 구현
  - 툴팁 키보드 대응 및 지도 줌 단계별 라벨 밀집도 조정
- **데이터 새로고침 & 안내**
  - 모달 하단 툴바에 새로고침 버튼, 마지막 요청 시각, 에러 토스트 처리
  - 데이터 단위/업데이트 주기/문의 채널 정보를 토글 섹션으로 제공

### Phase 3. 고급 시각화 및 접근성 최적화
- **다중 기간 비교 분석**
  - 7일·30일·90일·전체 기간을 비교하는 멀티 축 라인/에어리어 차트 개발
  - 전년 동월 대비, 증감률, KPI 카드 계산 로직 및 반응형 레이아웃 전환 처리
- **접근성 고도화**
  - 색각보정 팔레트 도입, 대비 4.5:1 이상 검증, 단축키(`?` 모달) 안내
  - `prefers-reduced-motion` 감지 시 애니메이션 비활성화, CSV 다운로드/표 뷰 제공
- **성능·운영 자동화**
  - 집계 함수 재시도/Slack 알림, BigQuery Export 파이프라인 구축
  - `StatisticsModal` 컨테이너와 `Charts`/`MapView`/`SummaryPanel` 컴포넌트 모듈화
  - Storybook 스냅샷, Lighthouse CI, Playwright 시각 회귀 테스트 추가

## 3. 공통 기술 과제
- Firestore 보안 규칙: 읽기 전용 API, 캐시 TTL 공유, 향후 쓰기 기능 대비 정책 수립
- 차트 라이브러리 선택(예: Recharts, ECharts) 및 접근성 확장 가능성 검증
- 상태 관리 전략(Zustand/Recoil)과 URL 동기화 방식 정리
- 오류/장애 모니터링(Sentry)과 로깅 스키마 설계

## 4. 검증 및 배포 체크리스트
1. Cloud Function 집계 잡 로컬/스테이징 검증, 실패 알림 동작 확인
2. 프런트엔드 유닛/통합 테스트 추가(필터, drill-down, 접근성)
3. Lighthouse 접근성 스코어 ≥ 95, 색상 대비 자동 테스트 수행
4. Storybook/Playwright 리그레션 파이프라인 CI 통합 후 메인 배포
