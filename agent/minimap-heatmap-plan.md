# 미니맵 실종 신고 히트맵 기획안

## 1. 목표
- 통계 모달의 미니맵 섹션을 대한민국 지도 실루엣으로 교체
- 지역별 신고량을 색상 그라데이션(노랑 → 주황 → 빨강 → 백색)으로 시각화해 직관적 비교 제공
- hover/포커스/선택 시 상세 정보를 제공해 드릴다운 경험 강화

## 2. 데이터 및 전처리
- **입력 데이터**: `stats/regionDaily` → `regions.{regionId}.totalCases` 및 `activeCases`
- **정규화**: 전체 신고량 대비 지역별 비율 계산 (0~1 범위)
- **구간 설정**: 5단계 색상 버킷 (예: 0~10%, 10~30%, 30~50%, 50~70%, 70% 이상)
- **지도 분할**: 행정동 GeoJSON (시·도 단위) 사용, 프런트에서 캐싱
- **퍼포먼스**: topojson → SVG path 변환 후 react-konva 혹은 D3로 렌더링

## 3. 시각 디자인
- **기본 팔레트**: `#FFFFFF`(최저) → `#FFF7CC`(노랑) → `#FDBA74`(주황) → `#F97316`(강한 주황) → `#DC2626`(적색 최고)
- **색상 규칙**: 신고량이 높을수록 더 뜨거운 색(백→노→주→적)으로 수렴, 최대 구간은 순수 적색 강조
- **지도 윤곽선**: 연한 회색(`rgba(148,163,184,0.5)`)로 시·도 경계 표시
- **선택 상태**: 선택 지역 path에 2px 흰색 스트로크 + 반투명 그림자
- **지도 배경**: 반투명 짙은 남색(#0f172a, opacity 0.05) 그라데이션으로 대비 확보

## 4. UX 인터랙션
- **Hover/Focus**: 해당 시·도 경로 하이라이트 + 툴팁(지역명, 총 신고/활성 건수, 전체 대비 %)
- **클릭/엔터**: 하단 드릴다운 패널에 지역 고정 → `useRegionStatsData` 상태 업데이트
- **키보드 내비게이션**: Tab 순서에 따라 path 접근 가능, 포커스 링 적용
- **선택 유지**: 모달 내 다른 UI 조작 시에도 선택 상태 유지, 닫으면 초기화
- **범례**: 지도 우측 상단에 수평형 범례 추가 (색상 + 범위값)
