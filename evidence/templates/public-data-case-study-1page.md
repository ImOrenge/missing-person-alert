# MissingAlert 공공데이터 활용사례 1페이지 — 제출 전 초안

> 실제 3개 연속 공개 승인 월과 전수 대조가 완료되기 전에는 제출용 수치를 채우지 않는다.

## 사례명

경찰청 공개 실종정보의 시민 접근성과 확산성을 높이는 민간 공익 데이터 서비스

## 문제와 해결

공식 실종정보가 존재하더라도 시민이 지역·지도·검색·통계 맥락에서 지속적으로 발견하고 안전하게 공유하기는 어렵다. MissingAlert는 공식 원문을 보존·검증·정규화하고 사건별 출처를 표시한 뒤 검색·지도·통계·공유 흐름으로 연결한다.

```text
공식 데이터 → 원본 metadata·hash → 검증 → 정규화 → 공개 → 행동 측정 → 관리자 승인 Impact
```

## 차별성

- 경찰 공식 서비스를 대체하지 않는 민간 접근성·확산 레이어
- 사건·통계 단위 출처와 마지막 확인 시각 추적
- 현재 사건 탐색과 연도별 공식 통계 연결
- 노출→상세→공유→공식 경로 이동을 개인정보 없이 측정
- 종결 비공개, 공개 방법론, 데이터 품질 처리 이력
